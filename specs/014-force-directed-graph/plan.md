# Implementation Plan: Obsidian-Style Force-Directed Graph View

**Branch**: `014-force-directed-graph` | **Date**: 2026-06-09 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/014-force-directed-graph/spec.md`

## Summary

Replace the floating keyword panel (feature 013) with a true **force-directed graph** in the Obsidian graph-view style. A center keyword node sits in the middle; clicking a node springs its related keywords outward via physics; clicking again collapses them; nodes can be dragged; hovering a node highlights only its directly-connected neighbors. Built on `d3-force` (already bundled in the existing `d3@7` dependency) for physics, with React + SVG for rendering — matching the project's existing "d3-for-math, React-for-DOM" pattern. The graph reuses the `KEYWORD_SUGGESTIONS_MAP` adjacency data and keeps news filtering intact by syncing the active keyword set to the existing store.

## Technical Context

**Language/Version**: TypeScript 6 / React 19 / Next.js 16

**Primary Dependencies**: `d3@^7.9.0` (d3-force, d3-drag — already installed), Zustand 5 (store), Framer Motion 12 (node mount/unmount polish only), TailwindCSS 4

**Storage**: Client-side Zustand store (active keyword set only); graph view state is component-local

**Testing**: Vitest 4 + @testing-library/react 16

**Target Platform**: Web browser, desktop-primary (360px left panel), responsive fallback for mobile via pointer events

**Project Type**: Next.js web application (single-page, client-side feature)

**Performance Goals**: ~60fps for expand/collapse/drag up to ~50–60 live nodes; idle simulation parks at ~0 CPU when settled

**Constraints**: Panel width 360px desktop / full-width mobile; child unfold animation begins <0.5s after click; hover highlight <0.2s

**Scale/Scope**: Up to ~60 simultaneous live nodes; expansion depth ≥3 levels

## Implementation Phases

### Phase 1: Graph Tree Data Layer
- **1.1** Create `src/utils/graphTree.ts`: `buildInitialNodes()` (root nodes from active keywords / trending), `getChildren(nodeId)` (from `KEYWORD_SUGGESTIONS_MAP`, deduped against live set), `collectDescendants(nodeId, links)` (for collapse). Pure functions, no React/d3.
- **1.2** Unit tests `tests/utils/graphTree.test.ts`: children resolution, dedup, recursive descendant collection, leaf detection.

### Phase 2: Force Simulation Hook
- **2.1** Create `src/hooks/useForceSimulation.ts`: own a `forceSimulation` in a ref with `forceLink`, `forceManyBody`, `forceCenter`, `forceCollide`; `tick` bumps a render version; expose `reheat()` and `setFixed(id,x,y)`. Update sim nodes/links when live set changes.

### Phase 3: Presentational Components
- **3.1** `GraphLinkView.tsx` — SVG `<line>` reading `source.x/y`, `target.x/y`; `isHighlighted` / `isDimmed` styling.
- **3.2** `GraphNodeView.tsx` — positioned node, size/color by depth & children state, expand affordance for collapsed-with-children, pointer handlers, Framer Motion mount/unmount.

### Phase 4: Panel Assembly & Interactions (US1 → US2 → US3)
- **4.1 (US1)** `ForceGraphPanel.tsx`: container + ResizeObserver; live nodes/links state; render links + nodes; **click → expand/collapse** with descendant cleanup; reheat on change; sync active keywords to store.
- **4.2 (US2)** Add **drag**: pointerdown record → pointermove >4px sets `fx/fy` + reheat → pointerup clears fix; click/drag disambiguation via 4px threshold.
- **4.3 (US3)** Add **hover highlight**: hoveredId → neighbor id set → dim non-neighbors (nodes + links).

### Phase 5: Integration & Cleanup
- **5.1** `page.tsx` swap import KeywordGraphPanel → ForceGraphPanel (identical props).
- **5.2** Delete superseded 013 components/hook after verifying no remaining imports.
- **5.3** `npx tsc --noEmit` + `npm test` green; manual `npm run dev` validation of all FRs.

## Key Design Decisions

| Decision | Choice | Reference |
|----------|--------|-----------|
| Visualization library | d3-force + custom React/SVG (no new dep) | research.md D-001 |
| Sim ↔ React bridge | simulation in ref, tick → version counter | research.md D-002 |
| Expand/collapse model | lazy children from adjacency map, `expanded` flag | research.md D-003 |
| Unfold animation | force simulation IS the spring | research.md D-004 |
| Click vs drag | 4px movement threshold | research.md D-005 |
| Hover highlight | neighbor id set, opacity dim | research.md D-006 |
| Drag fixing | fx/fy during drag, cleared on release | research.md D-007 |
| State ownership | view state local; active keywords → store | research.md D-008 |
| Performance | node cap ~60, sim parks at low alpha | research.md D-009 |
