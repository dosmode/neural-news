# Implementation Plan: Floating Keyword Graph Explorer

**Branch**: `013-keyword-graph-explorer` | **Date**: 2026-06-09 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/013-keyword-graph-explorer/spec.md`

## Summary

Replace the existing 3-layer neural network panel (`NeuralPanel.tsx`) with a floating keyword graph explorer. Users add keywords that drift freely in the panel; each keyword automatically spawns 3–5 related suggestion nodes. Clicking a suggestion promotes it to a full keyword and spawns further derivations — creating an Obsidian-style cascading exploration experience. The new panel is a drop-in replacement maintaining all existing keyword ↔ news filtering wiring.

## Technical Context

**Language/Version**: TypeScript 6 / React 19 / Next.js 16

**Primary Dependencies**: Zustand 5 (state), Framer Motion 12 (floating animation), TailwindCSS 4 (styling), D3 7 (available but not needed for this feature)

**Storage**: Client-side Zustand store only (no persistence change)

**Testing**: Vitest 4 + @testing-library/react 16

**Target Platform**: Web browser, desktop-primary (360px left panel), responsive fallback for mobile

**Project Type**: Next.js web application (single-page, client-side feature)

**Performance Goals**: 60fps continuous drift animation for up to 20 simultaneous nodes

**Constraints**: Panel width 360px desktop / full-width mobile, max 8 active keywords (existing constraint), suggestions appear within 500ms of keyword addition

**Scale/Scope**: ~8 keyword nodes + ~5 suggestions each = up to ~48 nodes (in practice ~10–20 visible at once due to collapse/dismiss)

## Implementation Phases

### Phase 1: Type Definitions & Data Layer

**1.1 Extend types** (`src/types/index.ts`)
- Add `parentId?: string | null` to `KeywordDef`
- Add `SuggestionDef` interface: `{ id, label, sourceKeywordId, isDismissed }`

**1.2 Create keyword suggestion service** (`src/services/keywordSuggestions.ts`)
- `KEYWORD_SUGGESTIONS_MAP: Record<string, string[]>` — curated adjacency data covering all TRENDING_POOL entries + 20 common user topics
- `getSuggestionsFor(keywordId, existingKeywords, existingSuggestions): string[]` — returns 3–5 suggestions, excluding already-active keywords and dismissed suggestions
- Fallback: if keywordId not in map, return 3 items from TRENDING_POOL not in existingKeywords

**1.3 Extend Zustand store** (`src/store/useStore.ts`)
- Add `suggestions: SuggestionDef[]` to initial state
- Add `addSuggestions(sourceKeywordId, labels)` action
- Add `acceptSuggestion(id)` action — promotes to keyword, triggers suggestion generation hook
- Add `dismissSuggestion(id)` action — sets `isDismissed: true`
- Modify `removeKeyword(id)` — cascade: remove suggestions for that keyword + remove child keywords (where `parentId === id`) + their suggestions

### Phase 2: Suggestion Trigger Hook

**2.1 Create hook** (`src/hooks/useKeywordSuggestions.ts`)
- `useKeywordSuggestions()` — watches `keywords` array length
- When a new keyword appears, calls `getSuggestionsFor()` and dispatches `addSuggestions()`
- Prevents duplicate suggestion generation (tracks last-processed keyword ids with a ref)

### Phase 3: UI Components

**3.1 FloatingKeywordNode** (`src/components/neural/FloatingKeywordNode.tsx`)
- Renders a Framer Motion `motion.div` positioned absolutely at `(x, y)`
- Continuous drift animation: randomized `x/y` keyframe arrays, `repeat: Infinity`
- Two visual states: active (neon-blue glow) / inactive (white/30 dim)
- Remove button (×) on hover

**3.2 SuggestionNode** (`src/components/neural/SuggestionNode.tsx`)
- Similar to `FloatingKeywordNode` but with:
  - 50% opacity, dashed border, neon-purple color scheme
  - "Accept" action on click (entire node clickable)
  - "Dismiss" (×) button on hover
  - Slower, gentler drift animation amplitude

**3.3 GraphEdges** (`src/components/neural/GraphEdges.tsx`)
- SVG overlay (absolute inset-0, pointer-events-none)
- Curved paths (`M sx sy C ... tx ty`) from keyword node centers to suggestion node centers
- Dashed stroke, `animate-neural-flow` class (reuses existing CSS animation)
- Edge opacity: keyword-to-suggestion edges are dim (0.3); keyword-to-keyword edges are slightly brighter

**3.4 KeywordGraphPanel** (`src/components/neural/KeywordGraphPanel.tsx`)
- Manages `positions: Map<string, {x, y}>` in local state (assigned on node mount)
- `assignPosition(nodeId)` — finds least-populated quadrant in panel bounds
- Renders `FloatingKeywordNode` for each `keyword` + `SuggestionNode` for each non-dismissed `suggestion`
- Renders `GraphEdges` SVG overlay
- Renders `AddKeywordControl` (reused/adapted from NeuralPanel)
- Empty state hint when no keywords exist

### Phase 4: Integration & Cleanup

**4.1 Update page.tsx** — swap `NeuralPanel` → `KeywordGraphPanel` import (same prop signature)

**4.2 Delete NeuralPanel.tsx** — after verifying no other imports

**4.3 Update AppState type** in `types/index.ts` with new store actions

### Phase 5: Tests

**5.1 Unit test: suggestion service** (`tests/services/keywordSuggestions.test.ts`)
- `getSuggestionsFor` returns correct count
- Excludes already-active keywords from suggestions
- Excludes dismissed suggestions
- Falls back gracefully for unknown keywords

**5.2 Unit test: store actions** (`tests/store/suggestions.test.ts`)
- `addSuggestions` populates state correctly
- `acceptSuggestion` moves suggestion → keyword + generates new suggestions
- `dismissSuggestion` sets isDismissed without removing entry
- `removeKeyword` cascades to suggestions + child keywords
