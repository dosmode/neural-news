# Implementation Plan: Graph Overview, Natural UX & Clicked-Node Article Sync

**Branch**: `015-graph-overview-news-sync` | **Date**: 2026-06-09 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/015-graph-overview-news-sync/spec.md`

## Summary

Refine the force-directed keyword graph (feature 014) with three changes: (1) **fix** the bug where clicked related nodes don't appear in the article results — switch the news active-set priority from depth-based to **selection-recency** based; (2) render a **default overview** on load by batch-expanding each root one level; (3) make interactions **more natural** via radial layout seeding and tuned simulation physics (centering forces, friction, collision spacing). All changes are localized to the existing graph component, simulation hook, and graph-tree util — no new files or dependencies.

## Implementation Phases

### Phase 1: Data Layer (graphTree)
- **1.1** Add `selectedAt: number` (optional) to `GraphNode` in `src/utils/graphTree.ts`.
- **1.2** Add `buildOverview(roots, dims)` → returns `{ nodes, links }` for roots + their depth-1 children, with radial seeding for roots and parent-relative seeding for children; roots get higher `selectedAt` than children.
- **1.3** Update `tests/utils/graphTree.test.ts` for `buildOverview` (root+child counts, depth-1 only, links wired, leaf roots have no children).

### Phase 2: Simulation Tuning (US3)
- **2.1** In `src/hooks/useForceSimulation.ts`: add `forceX(w/2).strength(0.04)` + `forceY(h/2).strength(0.04)`; set `velocityDecay(0.45)`; give `forceCollide` a strength (~0.85). Keep signature unchanged.

### Phase 3: News Sync Fix (US1 — P1, the bug)
- **3.1** In `ForceGraphPanel.tsx`: change `syncToStore` to sort by `selectedAt` descending (recency) before the cap.
- **3.2** Introduce a `selectionCounter` ref; on node click, set `node.selectedAt = ++counter` (most recent).
- **3.3** Update click handling so leaf nodes also select-for-news (don't early-return without syncing); nodes with children still expand/collapse.
- **3.4** Ensure collapse/remove re-runs `syncToStore` so deselected keywords drop from news (FR-004).

### Phase 4: Default Overview (US2 — P2)
- **4.1** Replace the root-only init effect with a batched `buildOverview` init: build roots + depth-1 children in one update, sync to store ONCE, reheat. Respect the 60-node cap.
- **4.2** Verify expand/collapse still works on already-expanded roots (toggle from expanded → collapsed and back).

### Phase 5: Selected Indicator (US1/US3 polish)
- **5.1** Derive `activeNewsIds` (top-N by `selectedAt`) in `ForceGraphPanel.tsx`; pass `isSelected` to `GraphNodeView`.
- **5.2** In `GraphNodeView.tsx`, render a distinct accent ring when `isSelected`.

### Phase 6: Validation
- **6.1** `npx tsc --noEmit` clean.
- **6.2** `npm test` green (updated graphTree tests + existing suite).
- **6.3** `npm run dev` manual: overview on load; click child → its articles appear; deep node reflected; smooth drag/hover/spread.
